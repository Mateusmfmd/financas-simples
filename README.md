# Finanças Simples

Visão mensal para decisões financeiras melhores.

## Demo

Esta é uma aplicação independente, com interface responsiva e interações funcionais no navegador.

## Problema

Receitas, despesas e categorias organizadas para transformar números em decisões.

## Funcionalidades

- Interface responsiva e mobile-first.
- Estados de interação e feedback visual.
- Componentes visuais com hierarquia clara.
- Dados demonstrativos seguros, sem credenciais.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript puro

## Como executar

Abra `index.html` no navegador ou execute:

```bash
python3 -m http.server 8000
```
